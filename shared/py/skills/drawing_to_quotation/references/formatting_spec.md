# 报价单格式规范（drawing-to-quotation-2026-07-01-v3）

本规范由 `scripts/fill_quote.py` 实现。常量集中在脚本顶部，按项目微调。
V3 排版与 V2 完全一致，只是**数据来源从写死的 DATA 换成 products.json**（见 `data_schema.md`）。

## 列定义（御見積書 典型布局）

| 列 | 字段 | 内容 | 对齐 | 字号 | 备注 |
|----|------|------|------|------|------|
| A | No | 行号 1..n | 居中 | 11 | |
| B | ITEM No, | 品番（一个品番一行） | 居中·加粗 | 11 | wrap；待确认项前加 ⚠ |
| C | 商品名 | 日语\n\n中文 | 居中 | 11 | wrap，**日中空行分隔** |
| D | 参考写真 | 裁剪产品图（统一尺寸） | 居中 | — | OneCellAnchor 精确居中 |
| E | 仕様・規格 | 日语逐条\n\n中文逐条 | 左+缩进1 | 10 | wrap，**日中空行分隔** |
| F/G/H | W/D/H | 外形尺寸(mm) | 居中 | 11 | 整数；来自 JSON 视觉确认值 |
| I | 数量 | 个数 | 居中·**加粗** | **14** | **无填充色**，格式 `#,##0`（千位分隔） |
| J | 単位 | pcs | 居中 | 11 | |
| K | ㎥ | 体积 | 居中 | 11 | `=F*G*H*I/1000000000*1.1`，格式 `0.00` |
| L | 単価・$ | 单价 | 右 | 11 | **留空**，格式 `"US$"#,##0` |
| M | 小計・$ | 小计 | 右 | 11 | `=IF(L="","",L*I)`（单价空则不显示0） |
| N | 備考 | 日语\n\n中文 | 左+缩进1 | 9 | wrap，**日中空行分隔**；待确认项淡黄高亮 |

## 统一行高算法（核心）

1. 对每个 E 列单元格文本，按「每行可容纳全角字数 CPL_E（默认17）」估算视觉行数：
   显式 `\n` 分段；空行计 1 行；每段宽度 = Σ(全角字=1.0, 半角字=0.55)，行数 = ceil(宽度/CPL_E)，至少 1。
2. 取所有 E 单元格的**最大视觉行数** `max_lines`。
3. `行高(pt) = max_lines × 行距(LINE_PT=14) + 上下留白(PAD_PT≈34)`。
4. **全部数据行统一**采用此行高。
5. 校验：C列、N列、图片在此行高内同样不溢出（通常远小于 E 列，自动满足）。

## 参考图（截图）规范

- 裁剪画布 660×440（3:2）；嵌入物理尺寸 **208×139px**（同比例不变形）。
- 定位 `OneCellAnchor + AnchorMarker(col=3, colOff=16px, row, rowOff) + XDRPositiveSize2D(ext)`。
  - `row_off = (行高px − 139)/2`，行高px = 行高pt × 4/3。
- 约束：图片宽 < D列像素宽，图片高 < 行高像素，**水平+垂直居中**，绝不溢出。**所有产品图尺寸一致**。
- 同一页有多个品番（F01/F01A）→ 各行各裁一张（同页图），互不影响。

## 数量列(I) / 单价·合计

```python
cell.font = Font(name='微软雅黑', size=14, bold=True)   # 数量列
cell.fill = PatternFill(fill_type=None)                 # 去背景色
cell.number_format = '#,##0'                            # 千位分隔
```
- L（单价）留空 → M（小计）`=IF(L="","",L*I)` 不显示 0 → 合计 `=SUM(M...)` 为 US$0（待报价）。

## 待确认高亮（V3 扩展）

触发条件（任一）：备考含「要確認/待确认/重複/重复」；W/D/H 缺失；
**`dim_source≠"visual"` 或 `dim_evidence` 为空**（V3 新增：尺寸没看图确认也算待确认）。
呈现：品番(B列)前加 `⚠`，品番格 + 备考格淡黄 `FFFFF2CC` 高亮。

## 其它

- 数据区残留不规则合并单元格 → 写入前解除 start_row–last_row 范围内所有合并。
- 多余预留行 → 清空残留 K/M 公式，避免显示 0.00。
- 数据行四边统一细边框（thin, 灰 808080）。字体默认「微软雅黑」（中日文均可显示）。
