# 数据质量核对清单（drawing-to-quotation-2026-07-01-v3）

> V3 把「视觉读尺寸」和「一个品番一行」从「口头约定/文字说明」变成了**数据管线里的硬环节**：
> 尺寸不看图就没来源（extract_scaffold 置 null），品番不拆就不会同页并行（拆分在 scaffold 阶段发生）。
> 本清单据此核对。

## 〇、外形尺寸核对（V3 核心 · 几何优先）

| 核对项 | 判据 / 动作 |
|---|---|
| 先看 measured | 定 W/D/H **先看每条记录的 `measured`**（几何量取），别一上来就肉眼猜 |
| 几何高置信直采 | `confidence=high` 且该轴 `suspect_local=false`、`extent_ok=true` → 用 `overall_value`，`dim_source="geometry"` |
| 可疑用跨度兜底 | `suspect_local=true` 或 `extent_ok=false` → 用 `overall_by_extent`，Read 整页图核对，`dim_source="visual"` |
| 几何失败回看图 | `vector_ok=false` 或 `confidence=low` → Read `full_page_XX.png`，量**横跨整个产品**的外形线 |
| 取外形非部件 | W/D/H 一律取整个产品外形；抽屉/台面厚/隔板/把手间距等部件尺寸一律不取 |
| 深度 D | 看 `band_overalls` 里侧视图那一带；拿不准 Read 侧视图确认 |
| 三方交叉核对 | 定下的外形 ≈ `overall_by_extent` 且（有链时）≈ `chain_sum`，且 ≥ 该轴任何局部值 |
| 引出线密集 | 几何置信低时 `render_pages.py --dpi 300 --zoom-quadrants`；或 `measure_dims.py --clip` 隔离单视图再量 |
| 整体↔部件冲突 | **取整体**填 W/D/H，部件值写备考；用「分段之和≈整体」二次校验 |

## 一、一个品番一行 · 拆分核对（V3 核心）

| 核对项 | 判据 / 动作 |
|---|---|
| 变体各成一条 | 一页有 F01、F01A → JSON 里**两条记录**（两行），绝不合并成一行求和 |
| 数量各归各 | `qty` 是**该型号自己的数量**（F01:1 一行、F01A:2 一行），不再写「計3」合并 |
| 同页多品番图片 | 各行各裁一张同页产品图，互不影响 |
| scaffold 漏拆补救 | extract_scaffold 若没识别出某变体 → 看图时手动在 JSON 补一条记录 |

## 二、尺寸逐项核对

| 核对项 | 判据 / 动作 |
|---|---|
| 三维齐全 | W/D/H 都应有值；缺任一 → JSON 留 null → 自动标 ⚠ 高亮 |
| 合理范围 | 30–8000mm；超范围 → 复核（误抓比例尺/年份2024–2026/图号） |
| 单位换算 | 图纸为英寸(`inch`/`"`) → **×25.4 → mm**，备考注明原值 |
| 同品番一致性 | 同品番多页出现 → 核对各处 W/D/H 是否一致；不一致→备考标注+高亮 |
| 体积量级 | K 列体积算出后扫一眼数量级是否合理（异常→某维可能抓错） |

## 三、术语订正（fill_quote 的 `fix_terms()` 自动施加）

- メラミン化粧板（フォーミカ）→ 中文统一「**防火板**」（HPL），**不要**直译「三聚氰胺装饰板」。
- 日文原文保留不动，仅订正中文译文。完整术语见 `translations.md`。

## 四、成品自检（render_check 渲染后）

- 逐页看：含「要確認/重複」或未视觉确认的行是否已 ⚠ + 淡黄高亮；
- 不同型号(F01/F01A)是否各占一行、数量各归各；
- W/D/H 是否都在合理范围、单位正确；
- 中文规格是否已是「防火板」；单价空时合计为 US$0。
